# Runtime Health Socket RPC v1

> Status: Superseded by [v2](v2.md), and still accurate for every released
> version up to and including `2.4.x`. v2 removes `evidence.artifact_version`
> and is what the runtime serves from the following release.
> Source of truth: `ori/runtime_health_socket.py`, `ori/runtime.py`

Read-only runtime health RPC over Unix domain socket for local CLI diagnostics.

## Transport

- Protocol: AF_UNIX stream socket
- Default path: `/run/ori/health.sock`
- Dev fallback path: `/tmp/ori-health.sock` when `/run/ori/health.sock` is not writable
- Default mode: `0o660`
- Security model: local file permissions (no network listener)

## Request

Accepted request payloads:

- `GET_HEALTH`
- empty payload

Maximum request bytes: `1024`.

## Response Envelope

Success:

```json
{
  "schema_version": 1,
  "ok": true,
  "health": { "...": "..." }
}
```

Failure:

```json
{
  "schema_version": 1,
  "ok": false,
  "error": {
    "code": "unsupported_request",
    "detail": "send GET_HEALTH or empty request"
  }
}
```

### `commissioning` object
The commissioned safety binding the runtime holds, per
[commissioned-safety-binding/v1.md](../commissioned-safety-binding/v1.md).
Present whether or not a binding exists; a device with no actuating hardware
reports `binding_seq: 0` and an empty `zones` list.

A runtime may hold a binding **in force** or a **provisional** one, and the
difference is what it may do rather than how well it verified. Every field
below says which it describes, because a reader who has to infer it from
"accepted" will eventually infer wrong.

| Field | Type | Notes |
|---|---|---|
| `binding_seq` | `int` | Sequence of the binding **in force**; `0` when none is. A provisional binding never sets it, however recently it verified. |
| `binding_hash` | `string \| null` | Canonical hash of the binding **in force**; `null` when none is. |
| `anchors_configured` | `bool` | A current commissioning anchor is configured out of band. |
| `zones` | `array` | One object per **retained** zone, whether the binding holding it is provisional or in force: `zone_id`, `sensor_id`, `actuator` (`kind` and `identity`), `commissioned_mapping`, `circuit_proof` (`method`, `performed_at_ms`), `control_path_proof` (`method`, `performed_at_ms`, or `null` when the leg is absent), `state` (`provisional` or `in_force`), and `availability`. Reporting only in-force zones would hide the zone an installer is part-way through commissioning, which is the one they need to see. |
| `last_verdict` | `object \| null` | The most recent verification outcome for a presented document: `stage`, `reason` (`accepted` when it passed), `binding_seq` of the document, `at_ms`. `null` when no document has been presented since start. |
| `actuation_licensed` | `bool` | True only when a retained binding covers every declared actuator **and** every one of its zones carries **both** proof legs: a circuit leg whose method is not `undemonstrated`, and a control leg whose method is `commanded_and_observed` on a `local_gpio` actuator. Either leg absent or `undemonstrated` on any zone sets it false, as does a `firmware_channel` zone, whose control leg has no design yet. False withholds every actuation through the commissioned seam, the initialisation coil command included. This is the same condition as being in force, stated rather than referred to. |
| `zones[].availability` | `string` | `available` when this zone's mapping may be commanded, which requires **both** its legs proven; `unavailable` when it may not — either leg absent or `undemonstrated`, a `firmware_channel` actuator, or no binding retained. An unavailable zone is reported as unprotected and is **never** reported as protected: an undriven output preserves whatever controller-loss state the site commissioned, which this contract's counterpart is explicit may be `closed`. |
| `actuator` | `object \| null` | The local actuator driven through the commissioned seam, when one is connected: `zone_id`, `gpio_pin`, `active_high`, `binding_seq`, `coil` (`energised` or `de_energised`, read from the driver), and `last_command` (`outcome`, `coil_state`, `level`, `executed`) or `null` before any command. `null` when no declared actuator has a zone **in force** — a provisional zone is never connected, so it never has an actuator to report. |

Gateway site-health projection may include broker posture, state-store encryption,
and alert outbox posture per runtime node. It must exclude `remote_command_lockout`
sender maps because keys are phone numbers or channel identities.

- `request_too_large`

- `internal_error`
