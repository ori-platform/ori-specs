# Runtime Config Surface v1

> Status: Implemented baseline in `ori-runtime`
> Source of truth: `ori/config.py`, `ori.yaml.example`

This document captures cross-repo config keys that other Ori repos must align with.

## `device`

| Key | Type | Notes |
|---|---|---|
| `device_id` | `string` | Required runtime identity |
| `timezone` | `string` | IANA timezone. Resolution order is `device.timezone` -> host timezone auto-detect -> `UTC`. |

## `device_policy`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable remote policy fetch path |
| `url` | `string` | Must use `https://` when enabled |
| `auth_token` | `string` | Bearer token |
| `public_key_b64` | `string` | Ed25519 verification key |
| `request_timeout_ms` | `int` | Must be `>=100` |
| `max_clock_skew_s` | `int` | Must be `>=1` |
| `refresh_interval_s` | `int` | Must be `>=60` |

## `health_socket`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable local health RPC socket |
| `path` | `string` | Default `/run/ori/health.sock`; runtime may fallback to `/tmp/ori-health.sock` in dev environments when `/run` is not writable |
| `mode` | `int` | Unix permission mode (for example `0o660`) |

## `os_sandbox`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Attempt OS-level sandbox for community hooks |
| `require_for_community` | `bool` | Fail closed if OS sandbox unsupported |
| `exec_timeout_ms` | `int` | Child hook execution timeout (`>=100`) |
| `max_output_bytes` | `int` | Child output cap (`>=4096`) |

## `actions.sms`

| Key | Type | Notes |
|---|---|---|
| `transport` | `string` | `ip` \| `gsm` \| `hybrid` |
| `enabled` | `bool` | Enable SMS channel |
| `hybrid_order` | `string` | `ip_first` \| `gsm_first` (used only for `transport=hybrid`) |
| `AT_API_KEY` | `string` | Africa's Talking API key |
| `AT_USERNAME` | `string` | Africa's Talking username |
| `AT_SENDER_ID` | `string` | Optional sender ID |

### `actions.sms.gsm`

| Key | Type |
|---|---|
| `enabled` | `bool` |
| `port` | `string` |
| `baud` | `int` |
| `sim_pin` | `string` |
| `timeout_s` | `float` |
| `command_timeout_s` | `float` |
| `write_timeout_s` | `float` |

### `actions.sms.incoming_webhook`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable inbound approval webhook |
| `host` | `string` | Defaults to loopback for safe local bind |
| `port` | `int` | TCP bind port |
| `path` | `string` | Webhook path |
| `token` | `string` | Shared-secret token; required when webhook enabled |

## `actions.whatsapp`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable WhatsApp channel |
| `TWILIO_ACCOUNT_SID` | `string` | Twilio account SID |
| `TWILIO_AUTH_TOKEN` | `string` | Twilio auth token |
| `TWILIO_WHATSAPP_FROM` | `string` | Must start with `whatsapp:+` |

## `actions.offline_tokens`

| Key | Type |
|---|---|
| `enabled` | `bool` |
| `public_key_b64` | `string` |
| `max_clock_skew_s` | `int` |

## `actions.coap`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enables CoAP action path |
| `timeout_s` | `float` | Action/request timeout |
| `retries` | `int` | Retry attempts |
| `allowed_hosts` | `string[]` | Required allowlist for CoAP use |
| `commands` | `object` | Named command map for `coap_command` executor |

When any `protocol=coap` sensors are configured, host allowlist enforcement remains mandatory.

## `reasoning.capability_posture`

| Key | Type |
|---|---|
| `enabled` | `bool` |
| `probe_interval_seconds` | `int` (`1..30`) |
| `gateway_heartbeat_ttl_seconds` | `int` (`>=1`) |
| `internet_probe_host` | `string` |
| `internet_probe_port` | `int` (`1..65535`) |
| `internet_probe_timeout_ms` | `int` (`>=100`) |

## `reasoning`

| Key | Type | Notes |
|---|---|---|
| `default_tier` | `string` | Supported values in v1 runtime: `rule` \| `local`. `gateway`/`cloud` are reserved and rejected by config validation. |

## Deferred (post-v1.0.0): `reasoning.context_enricher` (reserved)

This block is intentionally **not part of the pre-v1 implemented surface**.
It is reserved for post-v1 cross-sensor prompt context fusion work.

Planned keys:

| Key | Type | Planned semantics |
|---|---|---|
| `enabled` | `bool` | Enable prompt-time device snapshot enrichment |
| `staleness_window_ms` | `int` | Freshness threshold for snapshot entries |
| `max_entries` | `int` | Hard cap for snapshot lines injected into prompt |
| `include_sources` | `bool` | Include source metadata labels in prompt snapshot |
