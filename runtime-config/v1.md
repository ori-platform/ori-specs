# Runtime Config Surface v1

> Status: maturity `draft`; compatibility `frozen` by shipment (runtime
> `30bdcda`, 2026-05-11; release v0.9.0-beta.2), baseline audit `pending`;
> adoption: consumer (runtime) `shipped` in v0.9.0-beta.2, `unassessed`;
> proof: end-to-end `none`, HIL `none`, production `none`. Record:
> [status/runtime-config/v1.json](../status/runtime-config/v1.json).
>
> Source of truth: `ori/config.py` at the freezing release, now the package
> `ori/config/` (loader in `ori/config/_config.py`), and `ori.yaml.example`
>
> [runtime-config/v2.md](v2.md) closes this surface with a machine schema,
> retires the keys that carried safety or trust authority, and carries the keys
> and rules documented after this version froze. No runtime accepts v2.

This document captures cross-repo config keys that other Ori repos must align with.

## `device_policy`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable remote policy fetch path |
| `url` | `string` | Must use `https://` when enabled |
| `auth_token` | `string` | Bearer token |
| `public_key_b64` | `string` | Ed25519 verification key |
| `request_timeout_ms` | `int` | Must be `>=100` |
| `max_clock_skew_s` | `int` | Must be `>=1` |
| `refresh_interval_s` | `int` | Must be `>=60` |

## `health_socket`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enable local health RPC socket |
| `path` | `string` | Default `/run/ori/health.sock` |
| `mode` | `int` | Unix permission mode (for example `0o660`) |

## `os_sandbox`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Attempt OS-level sandbox for community hooks |
| `require_for_community` | `bool` | Fail closed if OS sandbox unsupported |
| `exec_timeout_ms` | `int` | Child hook execution timeout (`>=100`) |
| `max_output_bytes` | `int` | Child output cap (`>=4096`) |

## `actions.sms`

| Key | Type | Notes |
|---|---|---|
| `transport` | `string` | `ip` \| `gsm` \| `hybrid` |
| `sender_id` | `string` | SMS sender identity |
| `api_key_env_var` | `string` | Env var name for IP SMS provider key |

## `actions.coap`

| Key | Type | Notes |
|---|---|---|
| `enabled` | `bool` | Enables CoAP action path |
| `timeout_s` | `float` | Action/request timeout |
| `retries` | `int` | Retry attempts |
| `allowed_hosts` | `string[]` | Required allowlist for CoAP use |
| `commands` | `object` | Named command map for `coap_command` executor |

When any `protocol=coap` sensors are configured, host allowlist enforcement remains mandatory.

## `reasoning.capability_posture`

## Deferred (post-v1.0.0): `reasoning.context_enricher` (reserved)

This block is intentionally **not part of the pre-v1 implemented surface**.
It is reserved for post-v1 cross-sensor prompt context fusion work.

Planned keys:

| Key | Type | Planned semantics |
|---|---|---|
| `enabled` | `bool` | Enable prompt-time device snapshot enrichment |
| `staleness_window_ms` | `int` | Freshness threshold for snapshot entries |
| `max_entries` | `int` | Hard cap for snapshot lines injected into prompt |
| `include_sources` | `bool` | Include source metadata labels in prompt snapshot |
