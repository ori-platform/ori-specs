# CLI Commands v1

> Status: Implemented baseline surface, with additional ecosystem commands planned
> Notes: runtime health RPC is implemented; CLI can consume it.

This document defines the minimum viable operator/developer CLI surface expected for `ori-cli`.

## Existing Runtime Entrypoint

| Item | Value |
|---|---|
| runtime entrypoint | `python -m ori.runtime` / `ori-runtime` |
| `--config` | optional, default `ori.yaml` |
| `--log-level` | `DEBUG/INFO/WARNING/ERROR` |

## MVP Command Set

### `ori doctor`

- checks configuration presence/validity
- checks runtime importability
- checks environment readiness (model file, SQLite path writable, alert env vars)

Exit codes:

- `0`: no FAIL checks
- `1`: at least one FAIL
- `2`: config file missing/unreadable

### `ori config validate`

- validates config against runtime config parser rules

Exit codes:

- `0`: valid
- `1`: invalid
- `2`: file not found / parse failure

### `ori skills list`

- lists skill packages discoverable from configured skills directory

Exit codes:

- `0`: one or more skills loaded
- `1`: no skills loaded / all invalid

### `ori skills validate`

- validates one skill (`--skill-path`) or all configured skills (`--config`)

Exit codes:

- `0`: all requested skills valid
- `1`: one or more invalid

### `ori skills reload --pid`

- sends `SIGHUP` to running runtime process

Exit codes:

- `0`: signal delivered
- `1`: process missing / signal error

### `ori state action-log`

- reads `action_log` SQLite table

Exit codes:

- `0`: query success
- `1`: DB error

### `ori state history --sensor-id`

- reads `sensor_history` SQLite table

Exit codes:

- `0`: query success
- `1`: DB error
- `2`: sensor not found

## Runtime Health Command

Runtime contract:

- socket path default: `/run/ori/health.sock`
- request: `GET_HEALTH` (or empty payload)
- response: JSON line with `schema_version`, `ok`, and `health` payload

Recommended CLI shape:

### `ori doctor runtime-health`

- connect to runtime health socket
- fetch one snapshot
- print summary for:
  - capability posture
  - sensor connectivity/staleness
  - device policy state
  - last alert timestamps
- return non-zero on unavailable socket or malformed response

## Bridge Note (`cli_bridge`)

A dedicated Python bridge module for CLI delegation is planned in ecosystem work, but is not currently present in runtime. Until introduced, CLI implementations should avoid claiming a bridge path as an existing runtime contract.
