# Event Schema v1

> Status: Implemented in `ori-runtime`
> Source of truth: `ori/network/events.py`, `ori/runtime.py`, `ori/network/deduplicator.py`, `ori/state/store.py`

This document defines canonical event/data contracts for runtime producers and consumers.

## SensorReading

| Field | Type | Required | Notes |
|---|---|---|---|
| `sensor_id` | `string` | Yes | Matches `sensors[n].id` in config. |
| `sensor_type` | `string` | Yes | Routing key basis for sensor events. |
| `value` | `float` | Yes | Runtime rule engine rejects NaN/Inf during evaluation. |
| `unit` | `string` | Yes | Unit string, adapter-defined. |
| `timestamp` | `integer` | Yes | Unix milliseconds UTC. |
| `quality` | `float` | Yes | Convention: `0.0..1.0` (not dataclass-enforced). |
| `metadata` | `object` | Yes | Adapter metadata. `metadata.source` is strongly recommended but not universally enforced. |
| `raw` | `bytes \| null` | No | Optional raw payload, not persisted in SQLite history. |

## OriEvent

| Field | Type | Required | Notes |
|---|---|---|---|
| `event_id` | `string` | Yes | UUID4 string. |
| `event_type` | `string` | Yes | Poll path uses `sensor.{sensor_type}`. Runtime also emits `power.low_battery_throttle`. |
| `device_id` | `string` | Yes | From config `device.id`. |
| `sensor_id` | `string` | Yes | Copied from reading. |
| `timestamp` | `integer` | Yes | Unix milliseconds UTC. |
| `reading` | `SensorReading \| null` | Yes | Null for system-level events. |
| `context` | `object` | Yes | Additional metadata for non-reading/system events. |
| `source` | `string` | Yes | Populated from `reading.metadata.get('source', '')` in poll path. May be empty for some adapters/events. |
| `fingerprint` | `string` | Yes | Populated for sensor poll events. Empty for non-reading events. |

### Fingerprint Computation

```
sha256(device_id + sensor_id + sensor_type + str(round(value, 1)))
```

Timestamp is intentionally excluded.

## ActionResult

| Field | Type | Required | Notes |
|---|---|---|---|
| `action_name` | `string` | Yes | Requested action. |
| `tier` | `string` | Yes | `A \| B \| C \| D`. |
| `executed` | `bool` | Yes | Whether the executor for the actually taken action succeeded. |
| `approved` | `bool \| null` | Yes | `null` for A/B/D. For C: `true` only for affirmative token; otherwise `false`. |
| `action_taken` | `string` | Yes | Executed action name (may be safe default for Tier C fallback). Empty string if execution failed. |
| `timestamp` | `integer` | Yes | Unix milliseconds UTC at dispatch completion. |
| `operator_response` | `string \| null` | No | Raw operator reply for Tier C flows. |
| `proposal_id` | `string \| null` | No | Short Tier C proposal nonce used by scoped approvals. |
| `safe_default_used` | `bool` | No | Whether Tier C fallback executed the safe default. |
| `correlation_id` | `string` | No | Shared event correlation ID for related action/reasoning records. |

### Tier C Semantics

- `approved=true`: operator affirmative token.
- `approved=false`: explicit NO, timeout/no response, or unrecognized reply.
- `executed` can still be `true` when `approved=false` if `safe_default_action` executes successfully.

## ReasoningResult

| Field | Type | Required | Notes |
|---|---|---|---|
| `text` | `string` | Yes | Human-readable reasoning output. |
| `tier` | `string` | Yes | `rule \| local_slm \| gateway`. Cloud reasoning is a gateway backend, not a runtime tier. |
| `model` | `string` | Yes | Model/provider label. |
| `tokens_used` | `integer` | Yes | `0` for rule engine path. |
| `latency_ms` | `integer` | Yes | End-to-end reasoning latency. |
| `confidence` | `float` | Yes | Confidence score. |
| `action_tier` | `string` | Yes | Intended action tier (`A..D`), clamped by matched trigger tier in elevator path. |
| `proposed_action` | `string \| null` | No | Optional single proposed action. |
| `prompt` | `string` | Yes | Prompt text used (for LLM paths). |
| `reasoning` | `string` | Yes | Optional longer reasoning text. |
| `reasoning_status` | `string` | No | `complete`, `incomplete`, or `skipped` for Tier B post-action enrichment. Empty for normal reasoning paths. |
| `correlation_id` | `string` | No | Shared event correlation ID for joining reasoning rows to related action rows. |

## EventBus Routing

Implemented runtime routing:

- if `event.reading != null`: route by `event.reading.sensor_type`
- else: route by `event.event_type`

## Deduplicator Contract

### Runtime Placement

In sensor poll path only:

1. append sensor history to SQLite
2. run deduplicator
3. publish non-duplicate to EventBus

Non-reading/system events bypass this sensor-poll dedup flow.

### Window Values

| Parameter | Value |
|---|---|
| suppression window | 5000 ms |
| record TTL | 30000 ms |
| cleanup schedule | every 5 minutes via compaction loop |

## SQLite Serialization (action_log)

```sql
CREATE TABLE IF NOT EXISTS action_log (
    id                 INTEGER PRIMARY KEY AUTOINCREMENT,
    action_name        TEXT    NOT NULL,
    tier               TEXT    NOT NULL,
    executed           INTEGER NOT NULL,
    approved           INTEGER,
    action_taken       TEXT    NOT NULL,
    operator_response  TEXT,
    proposal_id        TEXT    NOT NULL DEFAULT '',
    safe_default_used  INTEGER NOT NULL DEFAULT 0,
    device_id          TEXT    NOT NULL DEFAULT '',
    sensor_id          TEXT    NOT NULL DEFAULT '',
    sensor_type        TEXT    NOT NULL DEFAULT '',
    correlation_id     TEXT    NOT NULL DEFAULT '',
    trigger_name       TEXT    NOT NULL,
    timestamp          INTEGER NOT NULL,
    attestation_status TEXT    NOT NULL DEFAULT '',
    attestation_seq    INTEGER
);
```

`executed`, `approved`, and `safe_default_used` are stored as integer booleans where applicable; `approved` is NULL for non-approval flows.

`attestation_status` and `attestation_seq` are the evidence-chain attestation
columns for Tier C/D actions; their semantics are defined in `evidence/v1.md`.

Reasoning audit rows are stored separately in `reasoning_log`. Tier B post-action
flows use `correlation_id` to join the physical action result with the follow-up
reasoning enrichment.
